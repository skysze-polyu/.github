# .github — 账号级默认模板

这个仓库不是代码项目，是 **skysze-polyu 账号的默认模板仓库**。

GitHub 会自动把这里的文件作为「社区健康文件」继承给账号下所有**没有自己模板**的仓库：

| 文件 | 继承到 | 作用 |
|---|---|---|
| `ISSUE_TEMPLATE/*.yml` | 全部仓库 | 提请求时强制选类型、写验收标准 |
| `PULL_REQUEST_TEMPLATE.md` | 全部仓库 | 每次开 PR 自动带上自查清单 |
| `CONTRIBUTING.md` | 全部仓库 | 分支命名、合并策略、流程说明 |
| `SECURITY.md` | 全部仓库 | 密钥/凭据泄露怎么报 |

**不继承的部分**（必须在每个仓库的 Settings 里单独开）：分支保护、Actions 开关。

## 维护约定

- 改模板 = 开 PR，不直推 main
- 模板要短。一份 PR 模板超过 20 行就没人看了
- 新增仓库时不用复制任何文件，自动继承
